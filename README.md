# Học NLP tại HOU 
Dự án lưu trữ toàn bộ bài tập và mã nguồn môn **Xử lý ngôn ngữ tự nhiên** của mình tại Đại học Mở TP.HCM.

## Cấu trúc thư mục
* `NLP_Buoi1.ipynb` đến `NLP_Buoi3.ipynb`: Các bài lab thực hành trên lớp.
* `recurrent_neural_networks.py`: Code triển khai mạng nơ-ron tuần hoàn (RNN).
* `.gitignore`: Loại bỏ các file rác và môi trường ảo để dự án gọn nhẹ.

## 🛠 Công nghệ sử dụng
* Python 3.x
* PyTorch
* Jupyter Notebook
